# Icon customization

`default_app.svg` is the neutral built-in UI icon.

At runtime, use **Settings → Icons** to choose a program icon or top-left logo.
The selected paths are stored only in the user's local application settings.

For a custom Windows executable icon, place an `.ico` file at
`assets/icons/custom_app.ico` before running `python build.py --clean`.
Do not commit artwork unless you own it or have permission to redistribute it.
